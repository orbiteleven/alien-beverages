# Bulkhead Bloom

## Description
The relay bars out in the Anser Belt can't get fresh anything, so they built a drink around what ships: shelf-stable Synthline, a dash of void bloom, nectar, and sourfruit juice from concentrate. Somehow it works — sweet-tart and floral, clean as a wiped bulkhead. It's the drink you order when you want something pretty in a place that is aggressively not. Relay techs call it "the apology."

## Method
1. Shake 45ml Synthline 40, 20ml Oberon sourfruit juice, and 15ml glowcap nectar with ice.
2. Add 5ml void bloom and shake three more seconds.
3. Double-strain into a chilled shockglass.
4. Float one void bloom petal dead center.

## Bartender's notes
Synthline 40 is the workhorse here precisely because it has no opinions — don't upgrade it to something characterful or the bloom gets shouted down. Add the void bloom late like the spec says; a full shake knocks the top notes off it.

From-concentrate sourfruit runs sweeter than fresh, so if you've somehow got the real thing, bump the nectar to 20ml to rebalance. Drier: 10ml nectar. This one takes dilution poorly, so shake hard and short — watery apology is a genre nobody orders twice.
